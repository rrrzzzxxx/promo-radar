✈️ PromoRadar (飞鸟特价雷达) - 全网特价机票聚合与智能决策平台
“打破信息差，拒绝套路杀。用 AI 重新定义特价机票的发现与选择。”

📖 项目愿景 (Product Vision)
在当今的旅行市场中，各大航司与 OTA（在线旅游平台）频繁推出极具吸引力的特价机票、随心飞及盲盒活动。然而，对于普通消费者而言，寻找一张真正的高性价比机票正变得越来越困难。

PromoRadar 诞生于这一市场痛点。本项目旨在打造一个高保真、强交互的特价机票元搜索（Meta-Search）与智能导购原型。通过聚合全网大促信息，并引入大语言模型（LLM）进行规则拆解，PromoRadar 致力于帮助用户在信息洪流中高效发现底价，在复杂条款中安全做出选择。

🎯 核心痛点与解决方案 (Pain Points & Solutions)
本项目在设计之初，深度调研了用户在购买特价机票时的三大核心痛点，并针对性地给出了产品侧的解法：

痛点一：信息极度分散，难以“及时发现” (The Information Gap)
现象： 亚航大促在官网，随心飞在 APP，代理商特价在朋友圈，用户需要跨越数十个 APP 才能凑齐信息。

💡 解法：【聚合情报信息流】
打造全网实时的特价情报 Feed 流，统一卡片化展示基准价格、剩余时间与核心标签。辅以“航线搜索”与“降价订阅雷达”，变“人找票”为“票找人”。

痛点二：隐藏规则复杂，难以“避坑选择” (The Rule Trap)
现象： 看似 9 元的机票，加上税费、行李额、选座费后远超高铁；或者附带“屏蔽法定节假日”、“不可退改”等霸王条款。

💡 解法：【AI 购票精算师】
引入 LLM 大模型能力。用户只需点击一键扫描，AI 即可在秒级时间内阅读数万字的航司枯燥条款，精准提取“行李额度”、“税费陷阱”、“退改政策”，并给出通俗易懂的购买建议。

痛点三：平台价格不透明，存在“底价幻觉” (The Price Illusion)
现象： 同一张机票，在飞猪、携程、同程、去哪儿及航司官网的价格和搭售政策各不相同，用户手动比价极其疲惫。

💡 解法：【全网底价比价榜单】
采用类似“识货”的跨平台比价逻辑。在产品详情页，一键拉取全网 5 大核心平台的实时报价，按总价从低到高严谨排序。最高亮的标签永远属于真正的“全网底价”，提供极其顺畅的购买决策闭环。

🏗️ 产品架构与模块设计 (Module Design)
本项目本着“轻量化、沉浸感、高转化”的设计原则，搭建了以下核心功能模块：

1. 发现与聚合模块 (Discovery Module)
Hero Banner & 聚合主页：度假风视觉引入，高密度 4 列商品网格展示，强化价格冲突（现价 vs 划线原价）。

全局动态搜索：支持目的地、航司等多维度的模糊检索。

2. 决策与比价模块 (Decision & Comparison Module) - 核心亮点
沉浸式详情页：采用 OTA 行业标准的高级灰白底色与橙色渐变价格横幅，消除多余视觉干扰。

比价排行榜 (Meta-Search)：跨平台竞价排序 UI，凸显第一名的“全网底价”优势，配有直达购买的转化按钮。

AI 规则查杀：独立的智能评估区块，将长文本转化为结构化的避坑指南。

三栏式详情 Tab：图文详情、费用包含说明、退改签政策的标准化展示。

3. 互动与留存模块 (Engagement Module)
机票盲盒：针对无明确目的地、有选择困难症的年轻用户，提供 99 元随机抽选世界角落的趣味交互体验。

降价订阅雷达：用户设定心理预期底价与邮箱，系统后台盯盘，完成深度用户留存。

4. 服务支撑模块 (Service Module)
我的订单：1:1 还原电商级订单管理 UI（待付款、待出行、售后），支持状态查看。

帮助中心：解答常见购票疑虑，提供平台免责声明与客服入口。

💻 技术实现与交互设计说明 (Implementation Notes)
为了优先呈现产品结构与功能设计，快速验证业务逻辑，本项目采用了以下 MVP（最小可行性产品）策略：

技术栈：基于 Python + Streamlit 框架，辅以深度定制的 HTML/CSS 实现极高保真度的前端 UI（规避了传统数据报表感，实现了接近原生 App 的质感）。

动态渲染：通过注入 JavaScript 实现了“整卡可点”的流畅交互；采用动态 Session State 实现了无缝的单页路由（SPA）体验，彻底摒弃了割裂的侧边栏。

AI 引擎接入：底层支持标准的 OpenAI API 格式，可一键切换通义千问、DeepSeek 等大模型，实现了真实的 Prompt 工程与规则摘要能力。

数据流：当前采用结构化的高质量 Mock 数据（含多平台竞价阵列）来演示核心的比价与导购逻辑，架构上已预留真实爬虫接口（services/crawler.py）。

🚀 如何运行 (How to Run)
确保已安装 Python 3.8+ 环境。

安装核心依赖：

Bash
pip install streamlit openai
在项目根目录下运行应用：

Bash
streamlit run app.py
若要体验真实的 AI 避坑功能，请在页面右上角的「⚙️ AI配置」中填入您的大模型 API Key。
